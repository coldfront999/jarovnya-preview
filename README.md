# Жаровня

## [Выбрать интерфейс — восемь вариантов дизайна](https://coldfront999.github.io/jarovnya-preview/designs.html)

Сохранены первые три варианта и добавлены пять по референсам 2, 3, 4, 7, 8: Minimal Premium, Urban Dark, Authentic Craft, Neobrutalism, Story Style. У каждого есть клиентская часть и админка.

## [Открыть текущую Жаровню](https://coldfront999.github.io/jarovnya-preview/)

Тестовая веб-версия для телефона. Заказы остаются на устройстве и не отправляются ресторану. Код входа — 1111.

В карточках весовых блюд можно выбрать желаемые 300, 500, 800, 1000, 1500 г или свой вес. Итог рассчитывается по фактическому весу. Самовывоз шаурмы — примерно 15 минут; время остальных блюд подтвердит ресторан. В корзине у дополнений есть фото.
